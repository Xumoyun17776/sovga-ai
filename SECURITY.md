# Security Policy

## Supported Versions

Currently, the `main` branch is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security is a top priority for Sovg'a AI. If you discover a security vulnerability in our platform, please do not disclose it publicly.

Instead, please send an email to `security@sovga.uz` with a detailed description of the issue, steps to reproduce, and a proof of concept.

We will review the submission and respond within 48 hours.

### Scope

The scope of this security policy includes:
- AI API key exposure or prompt injection flaws
- Authentication and session bypass
- SQL Injection in Drizzle ORM queries
- Broken access controls (B2B Merchant vs Regular User)

Thank you for helping keep Sovg'a AI secure!
