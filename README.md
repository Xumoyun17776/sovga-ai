# Sovg'a AI 🎁 - The 1st Autonomous AI Shopping Telemetry Platform in Uzbekistan

![Sovg'a AI Hero](https://images.unsplash.com/photo-1607082348824-0a96f2a4b9da?q=80&w=2070&auto=format&fit=crop)

> Sovg'a AI is not just a marketplace or a simple search engine. It is a live **AI Arbitrage & Telemetry Engine** that continuously scans Uzbekistan's premier retail networks (Uzum, Texnomart, MediaPark, Olcha) to find the absolute lowest price, real availability, and certified warranty for any product.

## 🌟 Professional Features (Billion-Dollar Architecture)

- **Neural Vision Product Matcher:** Upload any image of a gadget or gift. Gemini 3.8 Vision instantly identifies the exact brand/model and finds the cheapest live price in Tashkent.
- **In-App Direct Checkout Protocol:** No redirects, no friction. Order directly inside the platform with Click, Payme, or Cash on delivery.
- **Social Wedding & Wishlist Protocol:** Create shareable luxury gift registries. Features strict reservation locking to prevent duplicate gifts and integrated Honeymoon Cash Funds.
- **Live Arbitrage Radar:** Autonomous crawlers bypass fake discounts and sponsored listings to find the mathematically optimal price across 6 different retailers.
- **PWA & Desktop App Ready:** Installable natively on iOS, Android, and Windows.

## 🛠️ Tech Stack

- **Frontend:** React 18, TypeScript, TailwindCSS, Vite, Zustand, React Query
- **Backend:** Node.js, Express, Drizzle ORM
- **Database:** PostgreSQL (Neon)
- **AI Core:** Google Generative AI (Gemini 3.8 Flash & Pro Vision)
- **Styling:** Cyber-Luxury Design System (Glassmorphism, Grain overlays, Fluid Typography)

## 🚀 Quick Start

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-org/sovga-ai.git
   cd sovga-ai
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Environment Setup:**
   Copy the example environment file and add your actual API keys.
   ```bash
   cp .env.example .env
   ```

4. **Database Setup:**
   Push the schema to your Postgres instance.
   ```bash
   npm run db:push
   ```

5. **Start the Development Server:**
   ```bash
   npm run dev
   ```

## 🔒 Security & Architecture
- **Auth:** Encrypted express-session based auth with bcrypt.
- **API Rates:** Built-in rate limiting to prevent DDOS and AI API abuse.
- **Data Integrity:** Strict TypeScript & Zod validation for all DB/API boundaries.
